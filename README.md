# Luma Telegram Bot

Приватный Telegram-бот и Mini App для аудита диалогов. Принимает текст и до 10 скриншотов, проверяет правила, легенду и качество общения, затем возвращает три безопасных варианта ответа на русском и английском.

## Возможности

- приватный доступ по Telegram ID;
- альбомы из 2–10 скриншотов;
- изображения обрабатываются в памяти, уменьшаются и очищаются от метаданных;
- структурированный AI-аудит;
- повторная проверка всех сгенерированных ответов локальным фильтром;
- Mini App с розовым мобильным интерфейсом и кнопками копирования;
- без регистрации и постоянной истории в приложении;
- webhook для размещения в Replit и long polling для локальной разработки.

## Настройка

1. Создайте бота через официальный `@BotFather` командой `/newbot`.
2. Добавьте секреты из `.env.example` в Replit Secrets или локальный `.env.local`.
3. Первый запуск без списка разрешённых пользователей покажет ваш Telegram ID. Добавьте его в `TELEGRAM_ALLOWED_USER_IDS` и перезапустите приложение.
4. После публикации укажите HTTPS-адрес приложения в `PUBLIC_BASE_URL`. Бот автоматически подключит webhook и кнопку Mini App.

Рекомендуемая стартовая модель задаётся как `gpt-5.4-mini`. Если у API-проекта нет доступного лимита, бот не падает и возвращает безопасный резервный разбор.

Никогда не публикуйте токен Telegram или API-ключ в GitHub и не отправляйте их в переписке.
